# Plataforma Rodoviaria

Repositorio publico da Plataforma Rodoviaria, uma iniciativa para uma plataforma nacional de logistica e transporte rodoviario.

## Conteudo inicial

- `docs/PROMPT_MESTRE.md`: especificacao base enviada para orientar o produto.
- `assets/brand/logistica-invisivel.png`: imagem de referencia visual recebida para o projeto.

## Observacao

O prompt em `docs/PROMPT_MESTRE.md` deve ser tratado como documento de requisitos e visao de produto. Ele nao substitui validacoes tecnicas, juridicas, fiscais, de seguranca ou de conformidade antes de qualquer implementacao real.

Definir a stack do MVP e criar a primeira estrutura da aplicacao sem misturar este repositorio com outros projetos locais.
